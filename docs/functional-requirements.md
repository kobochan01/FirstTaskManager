# 機能要件

## 機能一覧

### 1. ボード
- ボードを作成・削除できる
- ボード一覧を表示できる
- ボードに名前をつけられる
- ボード名を編集できる

### 2. リスト
- ボード内にリストを作成・削除できる
- リストに名前をつけられる
- リスト名を編集できる
- デフォルトのリスト：「Todo」「In Progress」「Done」

> データ仕様（文字数上限等）は基本設計フェーズで決定予定

### 3. カード
- リスト内にカードを作成・削除できる
- カードにタイトルをつけられる
- カードタイトルを編集できる
- カードを削除する際は確認ダイアログを表示する
- 空のタイトルではカードを作成・保存できない

### 4. カードの詳細
- カードに説明文を追加・編集できる
- カードに期限日を設定・編集できる

### 5. ラベル
- カードに色付きラベルを追加できる
- ラベルは複数つけられる

### 6. カードの移動
- カードをドラッグ＆ドロップでリスト間を移動できる

### 7. データ保存
- localStorage を使ってデータを保存する
- ブラウザを閉じても内容が消えない

データ構造の詳細は [データベース設計](./database-design.md) を参照。
