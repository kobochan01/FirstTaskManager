# 要件定義書

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| アプリ名 | FirstTaskManager |
| 概要 | Trello風のタスク管理アプリ |
| 利用者 | 個人（1名） |
| 利用環境 | Webブラウザ |

---

## 技術スタック

| 役割 | 技術 |
|------|------|
| フロントエンド | React |
| データ保存 | localStorage |
| スタイル | CSS |

---

## 機能要件

### 1. ボード
- ボードを作成・削除できる
- ボード一覧を表示できる
- ボードに名前をつけられる

### 2. リスト
- ボード内にリストを作成・削除できる
- リストに名前をつけられる
- デフォルトのリスト：「Todo」「In Progress」「Done」

### 3. カード
- リスト内にカードを作成・削除できる
- カードにタイトルをつけられる

### 4. カードの詳細
- カードに説明文を追加できる
- カードに期限日を設定できる

### 5. ラベル
- カードに色付きラベルを追加できる
- ラベルは複数つけられる

### 6. カードの移動
- カードをドラッグ＆ドロップでリスト間を移動できる

### 7. データ保存
- localStorage を使ってデータを保存する
- ブラウザを閉じても内容が消えない

---

## 非機能要件

- ログイン機能は不要
- 複数人での共有機能は不要
- 担当者機能は不要
