# 要件定義書

## プロジェクト背景・目的

本プロジェクトはプログラミングスクールの課題として作成するWebアプリケーションである。
Trello風のタスク管理アプリを自力で設計・実装することを通じて、以下の学習を目的とする。

- Reactを用いたコンポーネント設計とstate管理の習得
- ドラッグ&ドロップなどのインタラクションの実装経験
- localStorageを用いたクライアントサイドのデータ永続化の理解
- 要件定義から実装までの開発プロセスの体験

## 機能要件

### 1. ボード
- ボードを作成・削除できる
- ボード一覧を表示できる
- ボードに名前をつけられる
- ボード名を編集できる

> UI仕様（ワイヤーフレーム等）は今後の設計フェーズで追加予定

### 2. リスト
- ボード内にリストを作成・削除できる
- リストに名前をつけられる
- リスト名を編集できる
- デフォルトのリスト：「Todo」「In Progress」「Done」

> データ仕様（文字数上限等）は基本設計フェーズで決定予定

### 3. カード
- リスト内にカードを作成・削除できる
- カードにタイトルをつけられる
- カードタイトルを編集できる
- カードを削除する際は確認ダイアログを表示する
- 空のタイトルではカードを作成・保存できない

### 4. カードの詳細
- カードに説明文を追加・編集できる
- カードに期限日を設定・編集できる

### 5. ラベル
- カードに色付きラベルを追加できる
- ラベルは複数つけられる

### 6. カードの移動
- カードをドラッグ＆ドロップでリスト間を移動できる

### 7. データ保存
- localStorage を使ってデータを保存する
- ブラウザを閉じても内容が消えない

データ構造の詳細は [ER図](./er-diagram.md) を参照。
